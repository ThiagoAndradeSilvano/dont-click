# Client (Navegador)

Aqui fica toda a interface do jogador (HTML/CSS/JS ou Vite/TS).
> **Importante:** Nunca coloque respostas de enigmas diretamente no código do `client`, pois jogadores de jogos estilo *Don't Believe His Lies* sempre abrem o Inspecionar Elemento (F12) — a menos que a pista **seja** propositalmente escondida no HTML/Console!
